# Wadah gambar

Taruh file gambar di folder ini dengan **nama sesuai slot** (ekstensi bebas:
`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.svg`). Gambar langsung dipakai
tanpa perlu mengubah kode. Selama file belum ada, website menampilkan placeholder.

| Nama file (slot) | Tampil di | Ukuran disarankan |
| --- | --- | --- |
| `hero` | Latar hero beranda | 2880 × 2060 px (landscape) |
| `fasilitas-1`, `fasilitas-2`, `fasilitas-3` | Kartu foto fasilitas | 976 × 670 px |
| `auth` | Panel kiri halaman Login & Register | 1440 × 2048 px (portrait) |
| `laporan-1` … `laporan-4` | Foto kartu laporan dummy di dashboard (tanpa file: foto contoh Unsplash) | 800 × 500 px |
| `logo` (opsional) | Mengganti logo SVG bawaan | SVG, atau PNG ≥ 184 × 166 px |

Daftar slot lengkap ada di `src/data/images.js`.
